Getting your Anthropic API key

Takes about 2 minutes. This is the "bring your own key" part of Clipbench — you pay Anthropic directly for AI usage, at cost, with no subscription and no middleman markup.

1

Create an Anthropic Console account

Go to console.anthropic.com and sign up with email or Google. Note: this is the developer console — it's separate from the Claude chat app, even if you already pay for that.

2

Add credits

Open Billing and buy credits. $5 is plenty to start — analyzing a full 90-minute podcast typically costs a few cents to a few tens of cents depending on the model you choose in Clipbench, so $5 covers dozens of videos. Credits only get used when you analyze a video; transcription in Clipbench is local and always free.

3

Set a spend limit (optional, recommended)

On the same Billing page you can set a monthly spend cap. Set it to $5 or $10 and you can never be surprised — the worst case is Clipbench telling you the limit was reached.

4

Create the key

Go to API Keys → Create Key. Name it anything ("Clipbench" works), create it, and copy it immediately — keys start with sk-ant- and are shown only once. If you lose it, just delete it and make a new one.

5

Paste it into Clipbench

Open Clipbench → Settings → paste the key → hit Test. If it says the key works, you're done forever — there's nothing to renew.

Is my key safe in Clipbench? The key is stored only on your computer and is only ever sent to Anthropic's API. Clipbench has no servers — there's nowhere else for it to go. See the privacy policy.

Which model should I pick in Clipbench? Claude Opus 5 gives the sharpest clip picks and captions; Sonnet is ~40% of the cost and very good; Haiku is the budget option for high-volume clipping. You can switch anytime in Settings — the estimate shown before each analysis tells you what that video will cost.

Stuck? Email support@clipbench.app and we'll get you going.
